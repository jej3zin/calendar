# 📅 | calendar-13

Um **Web Component** de calendário alternativo baseado em:

- 13 meses
- 28 dias por mês
- 1 dia neutro
- Ano iniciando em **1º de abril**
- Estações fixas
- Fases reais da lua
- Planejamento agrícola sazonal

Tudo em **HTML + CSS + JS puro**, sem frameworks.

---

## ✨| Features

- 🧩 Web Component `<calendar-13>`
- 🌙 Fases reais da lua (cálculo astronômico)
- 🌱 Estações do ano fixas e previsíveis
- 🌾 Plantio e colheita (milho, feijão, batata, trigo)
- 🎨 Shadow DOM (CSS isolado)
- 🔌 Reutilizável em qualquer site
- 📦 Arquivo único JS

---

## 📦| Instalação

### Uso direto (sem build)

```html
<script src="calendar-13.min.js"></script>
<calendar-13></calendar-13>
```

## 🔧| Atributos HTML

```html
<calendar-13 theme="dark" start-month="7" lang="pt"> </calendar-13>
```
